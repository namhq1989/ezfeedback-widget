Enhanced EzFeedback Widget Demo

About EzFeedback

EzFeedback is a lightweight, customizable feedback widget that can be easily embedded on any website. This enhanced version includes server data loading capability.

New Feature: Server Data Loading

The enhanced EzFeedback widget now loads configuration data from a server after initialization. This includes:

  • Custom primary color
  • Dynamic category options

Note: For this demo, server data is simulated with a 1.5 second delay to demonstrate the loading state.

Key Features

  • Floating feedback button that expands into a full form
  • Light/dark theme toggle
  • Star rating system
  • Server-loaded category selection
  • Feedback text area
  • Optional email field
  • Fully responsive design
  • No external dependencies
  • Loading indicator for server data

Try It Now

You can see the EzFeedback widget in action on this page. Look for the feedback button in the bottom-left corner. Notice how it first shows a loading spinner while fetching data from the server.
