EzFeedback Widget Demo

About EzFeedback

EzFeedback is a lightweight, customizable feedback widget that can be easily embedded on any website. It provides a simple way for your users to share their feedback, thoughts, and suggestions.

Key Features

  • Floating feedback button that expands into a full form
  • Light/dark theme toggle
  • Star rating system
  • Category selection
  • Feedback text area
  • Optional email field
  • Fully responsive design
  • No external dependencies
  • Tiny footprint (less than 10KB)

Integration Example

<!-- Add this script tag to your website -->
<script
  src="ez-feedback.js"
  data-ez-feedback-id="your-project-id"
  data-ez-feedback-position="bottom-right"
  data-ez-feedback-size="medium"
  data-ez-feedback-color="#0072F5"
  data-ez-feedback-theme="light">
</script>

Try It Now

You can see the EzFeedback widget in action on this page. Look for the feedback button in the bottom-right corner!

Control Programmatically

<script src="ez-feedback.js"></script>
<script>
  // Initialize with custom options
  const widget = window.EzFeedback.init({
    projectId: 'your-project-id',
    position: 'bottom-right', // 'bottom-right', 'bottom-left', 'top-right', 'top-left'
    size: 'medium',
    primaryColor: '#0072F5',
    theme: 'light'
  });

  // Access methods programmatically
  document.getElementById('showWidget').addEventListener('click', function() {
    widget.showForm();
  });
</script>
